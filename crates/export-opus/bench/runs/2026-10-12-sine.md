# 2026-10-12 — half-scale 440 Hz bench

`cargo bench --workspace --bench sine` from `crates/export-opus`.

This file does not replace the silence row in [`2026-10-12-packet.md`](2026-10-12-packet.md) (encode p50 350 ns). No speedup against that row is claimed.

Threading off. Clock is `std::time::Instant`. Nearest-rank p50 and p99 over 20,000 calls after 1,000 warmup calls. Profile matches release: `opt-level = 3`, `lto = "thin"`, `codegen-units = 1`.

Timed calls: encode of the half-scale 440 Hz frame, and decode of that packet. The silence packet and the truncated-packet path are not in this bench.

FFmpeg still decoded the packet as a tone before these runs: RMS 10802.8, peak 16826, onset peak 4. The library did not call ffmpeg.
